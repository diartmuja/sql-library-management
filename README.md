# SQL Library Management

Ky projekt paraqet një sistem të thjeshtë për menaxhimin e librave duke përdorur SQLite.

## Niveli i përfunduar

Niveli i përfunduar: [shëno nivelin e detyrës këtu]

## Përmbajtja e projektit

- `create_tables.sql` - krijon tabelën `books`.
- `insert_data.sql` - përmban të dhënat për minimum 20 libra.
- `exercises.sql` - përmban SQL queries për ushtrimet e zgjidhura.
- `README.md` - përmban përshkrimin dhe udhëzimet për ekzekutimin e projektit.

## Si të ekzekutohet

Skriptat duhet të ekzekutohen në SQLite në këtë rend:

1. `create_tables.sql`
2. `insert_data.sql`
3. `exercises.sql`

Fillimisht krijohet tabela `books`, pastaj shtohen librat dhe në fund ekzekutohen queries për ushtrimet.

Skriptat mund të ekzekutohen edhe në sqliteonline.com.
